📦 mnncompress - Advanced Compression

🎯 Purpose

Apply compression techniques to PyTorch/TensorFlow models before MNN conversion. Produces compressed MNN models via MNNConvert.

🔧 PyTorch Methods

  • Pruning:
    • SNIPLevelPruner
    • SIMDOCPruner
    • TaylorFOChannelPruner
  • Quantization:
    • LSQQuantizer
    • WeightQuantizer
  • Other: low_rank_decompose, LOP

🔧 TensorFlow Methods

  • Pruning:
    • SNIPLevelPruner
    • SIMDOCPruner
    • TaylorFOChannelPruner
  • Quantization:
    • EMAQuantizer
    • LSQQuantizer
    • OAQQuantizer
    • WeightQuantizer
  • Other: sensitivity_analyzer, decomposition

🔧 Build System & CMake Options

CMake Configuration Flags

cmake .. \
  -DMNN_BUILD_CONVERTER=ON \
  -DMNN_BUILD_QUANTOOLS=ON \
  -DMNN_BUILD_TRAIN=ON \
  -DMNN_BUILD_OPENCV=ON \
  -DMNN_BUILD_AUDIO=ON \
  -DMNN_EVALUATION=ON \
  -DMNN_LOW_MEMORY=ON \
  -DMNN_USE_OPENCL=ON \
  -DMNN_USE_METAL=ON \
  -DMNN_USE_VULKAN=ON

🎯 Feature Flags

  • MNN_BUILD_CONVERTER - All model converters (ONNX, TF, Caffe, TFLite)
  • MNN_BUILD_QUANTOOLS - Quantization tools
  • MNN_BUILD_TRAIN - Training infrastructure
  • MNN_BUILD_OPENCV or MNN_BUILD_IMGPROC - CV wrapper
  • MNN_BUILD_AUDIO - Audio processing utilities
  • MNN_EVALUATION - Accuracy evaluation tools

🚀 Build Commands

# Full build with all tools
mkdir build && cd build
cmake .. -DMNN_BUILD_ALL=ON
make -j$(nproc)

# Or selective build
cmake .. \
  -DMNN_BUILD_CONVERTER=ON \
  -DMNN_BUILD_LLM=ON
make -j$(nproc)

Build outputs go to build/ directory
