03 / Core

Core 模块详解

框架的心脏 - 执行引擎与核心抽象

关键组件

  • Interpreter.cpp/hpp - 模型解释器
  • Session.cpp/hpp - 推理会话管理
  • Tensor.cpp/hpp - 张量数据封装
  • Pipeline.cpp/hpp - 执行流水线
  • Backend.cpp/hpp - 后端抽象基类
  • Op.hpp - 算子基类定义
  • BufferAllocator.cpp - 内存分配器
核心设计模式：采用 Interpreter + Session 分离设计，支持多实例并发推理

执行流程

// 1. 创建解释器 auto interpreter = Interpreter::createFromFile("model.mnn"); // 2. 配置会话参数 ScheduleConfig config; config.type = MNN_FORWARD_CPU; // 3. 创建会话 auto session = interpreter->createSession(config); // 4. 获取输入输出张量 auto input = interpreter->getSessionInput(session); // 5. 执行推理 interpreter->runSession(session);

09 / Design Patterns

关键设计决策

架构层面的核心设计思想

1. 后端抽象 (Backend Abstraction)

通过 Backend 基类统一抽象不同硬件平台，运行时动态选择最优后端

2. 内存池 (Memory Pool)

BufferAllocator 实现内存复用，减少频繁 malloc/free 开销

3. 算子融合 (Op Fusion)

Geometry 层将 Conv+BN+ReLU 等融合为单一内核，减少内存访问

4. 静态形状推断 (Static Shape)

编译期确定张量形状，预分配内存，避免运行时动态计算

5. 量化支持 (Quantization)

INT8/FP16 量化运算，配合 NPU 后端实现低功耗推理

6. 异构调度 (Heterogeneous)

CPU/GPU 混合调度，根据算子特性选择最优执行设备
