source/core 推理核心

核心模块

  • Interpreter - 模型加载与推理会话管理
  • Session - 推理会话生命周期
  • Pipeline - 算子调度与执行
  • Backend - 硬件后端抽象接口
  • Tensor - 数据张量容器

关键特性

  • NC4HW4 格式存储 (通道4分组 SIMD 优化)
  • RTTI 与异常禁用
  • C++11 标准
  • 异构后端调度

算子注册模式

完整的算子支持需要经过以下阶段：

1. Schema 定义 → schema/default/*.fbs (FlatBuffers) 2. 形状推断 → source/shape/ (计算输出形状) 3. 几何分解 → source/geometry/ (算子拆解优化) 4. 后端实现 → source/backend/*/Execution.cpp

示例结构

  • Convolution 算子 → ConvShape.cpp + ConvExecution.cpp
  • MatMul 算子 → MatMulShape.cpp + MatMulExecution.cpp
  • Attention 算子 → AttentionShape.cpp + AttentionExecution.cpp

架构总结

MNN 是一个图优化 + 异构后端调度架构的轻量级推理引擎。

核心优势：多后端支持、LLM/Diffusion 原生支持、高性能优化、小体积部署
