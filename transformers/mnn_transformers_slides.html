EAGLE

Efficient Attention-Gated Language Model

  • Small draft model predicts multiple tokens
  • Target model verifies in parallel
  • Reject incorrect drafts
  • 2-3x speedup achievable

MTP

Multi-Token Prediction

  • Single forward generates N tokens
  • No draft-target verification needed
  • Trade latency for throughput
  • Supports N=2,4,8...
// Speculative loop
auto draft_tokens = draft_model->predict(prompt, N);
auto [accepted, rejected] = target_model->verify(draft_tokens);
if (accepted == N) {
  // All tokens valid, huge speedup!
} else {
  // Rollback and regenerate
}
